Run It Yourself

Installation & Run Commands

All code requires Python 3.8+. Install dependencies once, then run any requirement independently.

pip install networkx numpy scipy matplotlib requests beautifulsoup4 streamlit plotly pandas

# Requirement 1 — Progressive Pruning benchmark and chart
python progressive_pruning_pr.py

# Requirement 2 — 791-node synthetic demo (no internet required)
python realistic_data.py --demo

# Requirement 2 — Live website crawl (internet required)
python realistic_data.py --scrape --url https://docs.python.org/3/ --depth 2

# All 6 PageRank methods + experiments
python all_6_methods.py
python experiments.py --exp all

# Interactive simulation engine (opens at http://localhost:8501)
streamlit run pr_simulator.py

# Search engine test suite (8/8 tests)
python search_engine_test.py
