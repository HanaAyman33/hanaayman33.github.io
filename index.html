Implementation

Six PageRank Computational Methods

All methods implemented from scratch and validated against each other. Complexity ranges from O(n³) to O(n).

Method 1

NetworkX Built-in

Primary reference implementation. Internally uses SciPy sparse matrices. Handles all edge cases automatically and serves as ground truth for accuracy comparisons.

Time O(k·(N+E)) Space O(N+E) Exact ✓
Method 2

Manual Power Iteration

Implements the PageRank formula directly using Python dicts. Every variable maps one-to-one to the mathematical definition. Fully transparent and auditable.

Time O(k·(N+E)) Space O(N+E) ~Exact
Method 3

Matrix Algebra (Exact)

Solves (I − αM)r = (1−α)/N·1 directly via NumPy LU decomposition. Single-step exact solution — but O(n³) makes it impractical beyond ~200 nodes.

Time O(N³) Space O(N²) Exact ✓
Method 4

SciPy Sparse (CSR)

Stores only non-zero matrix entries. For a web graph with 10 links per page, this eliminates 99.99% of wasted storage. Fastest iterative method.

Time O(k·E) Space O(N+E) ~Exact
Method 5

Monte Carlo Surfer

Simulates the random surfer directly. Error decreases as O(1/√R). Only O(N) memory — trivially parallelisable. Decisive advantage at web scale.

Time O(S·L) Space O(N) Approx
Method 6/7

HITS + Pruning (Custom)

HITS computes hub and authority scores for comparison. The custom Pruning variant freezes low-rank pages early for 1.53× speedup on large web-like graphs.

HITS O(k·m) 1.53× faster
