Project Overview

Five Requirements, One Complete System

Each requirement builds on the last — from implementing the raw algorithm to building a full search engine with real-time simulation. All six PageRank methods run on the same graph structure and are validated against an exact Matrix Algebra ground truth.

Requirement 1

Progressive Pruning PageRank

A novel enhancement to power iteration that freezes low-rank pages after convergence, eliminating redundant computation on pages that have already stabilised.

Algorithm: 10-iteration warmup → freeze pages below τ=0.5/N for 3+ stable rounds → continue updating active pages only. Frozen pages retain their last rank but still contribute outgoing link weight.
NumPyBenchmarkL1 Error = 0.001.25× at n=500

Realistic Large-Scale Data

Combined score = 0.6×PR + 0.4×TF-IDF. IDF uses smoothed formula log₁₀((N+1)/(df+1)) to prevent division by zero and handle terms in every document.

Rec 5 — Hub-and-Spoke vs Chain

Converting the chain structure to hub-and-spoke (Homepage links directly to all sections) eliminates rank bleed through long paths. In a chain, each hop multiplies rank by the out-degree factor. Hub-and-spoke gives every section a direct, undiluted link from the highest-authority page.

In the generic 5-page example (§4.7.8): chain start page gains +29.8%, chain end page loses −65.0%.

PR: 0.201128 → 0.280296 · Source: Figure 4.13, Section 4.7.5

Rec 2 — Create an Internal Hub Page

Old articles (nodes 7–12) previously linked to Homepage. Redirecting them to link directly to Top Story concentrated 6 sources of inbound rank onto the target page. Top Story climbs from rank #2 to rank #1.

This was the single largest gain in the entire optimisation sequence — more than any external link strategy. Approximately 6 × 0.032 = 0.192 rank flow redirected to Top Story.

Rec 3 & Rec 1 — Saturated (Zero Marginal Gain)

After reaching PR ≈ 0.396, adding multiple inbound links (Rec 3) and a high-authority external link (Rec 1) each produced exactly +0% improvement. Mathematical saturation: total rank is conserved (Σ PR = 1.0) and every page has a minimum floor of 0.01.

Note: Rec 1 (+287%) applies when a high-authority link is added before structural saturation (§4.7.1 standalone simulation).

⚡ The Critical Insight: Diminishing Returns

PageRank is a conserved probability distribution. Total rank always sums to 1.0. Once Top Story reaches PR ≈ 0.396, additional inbound links — even from high-authority external sources — produce mathematically zero improvement.

Every page has a hard minimum floor of (1−α)/N. The 14 other Metro Daily pages collectively cannot drop below 0.14. The remaining 0.46 is already structurally allocated and unavailable.

Σⅰ PR(i) = 1.0  ·  min PR(p) = (1−0.85)/15 = 0.01
✅ Phase 1 — Structural fixes first. Fix dangling pages, convert chains to hub-and-spoke, create internal hubs. These deliver the highest ROI: +3.2%, +39.4%, +41.2%.
🔗 Phase 2 — External links EARLY. Pursue high-authority inbound links before structural saturation. A single .edu or BBC link gives +287% at this stage.
🛑 After saturation — stop link-building. Further links produce zero marginal gain. Spend the budget on content or new pages instead.
